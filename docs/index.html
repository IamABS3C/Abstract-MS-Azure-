How to deploy

The shortest path from nothing to Azure telemetry flowing into Abstract. Every step has a button above and a CLI equivalent on each card.

  1. Event Hub estate, first Everything else consumes its outputs — note abstractDiagnosticsAuthRuleId and eventHubNames. One namespace per region that holds regional resources.
  2. Onboard the estate in report-only mode The governance pack starts as AuditIfNotExists: it changes nothing and tells you exactly which subscriptions and resources would be collected.
  3. Grant, then backfill Give the policy identities access to the hub, then run a remediation task — DeployIfNotExists never touches resources you already own.
  4. Identity telemetry One tenant-scope command covers the whole organisation. No Azure Policy can reach Entra ID, because there is no per-subscription object to evaluate.
  5. Then destinations Route Abstract's enriched output to Sentinel, an Event Hub, or both.

Three things that decide whether this works

The region rule. Azure Monitor rejects a diagnostic setting whose Event Hub is in a different region from the monitored resource. One namespace per region. Activity Log, Defender for Cloud and Entra ID are exempt — they are not regional.

Remediation is not optional. Policy fires on create or update, so your existing estate stays dark until a remediation task backfills it.

New subscriptions must land in the right management group. They default to Tenant Root, not your group — set the tenant's default management group or they silently miss the policy.

Scripts

The parts no template can do — and the guardrails that keep the templates honest.

ScriptWhat it does
scripts/Deploy-AbstractLogStreams.sh Deploy / Grant / Remediate / Status for the log-stream policy pack. Remediation is not optional — DeployIfNotExists never touches what you already own.
scripts/Deploy-AbstractAppReg.sh Bootstrap / DeployA / DeployB / Grant / Onboard / Remediate / Verify / Status. Bootstrap is the one step no template can do.
scripts/Deploy-AbstractEventHub.ps1 Menu-driven deployment of the Event Hub source stack, with preview and credential retrieval.
scripts/New-AbstractSentinelApp.ps1 Creates the Entra app for the Sentinel destination and grants both required DCR roles.
scripts/validate-templates.py Enforces what az bicep build cannot see: UI outputs match template parameters, no required parameter is unsupplied, and the UI model matches the deployment scope.
scripts/gen-deploy-links.py Regenerates every README table and the Pages site from this manifest, so a repo rename can never leave a stale button behind.
